# Beginner Orientation Protocol

## Purpose
Support a user who has no established Document Vision research map.

## Required Field Primer
Cover:
- task families;
- data forms;
- metrics;
- representative method families;
- mature / active / emerging subareas;
- low-resource vs compute-heavy branches;
- terminology aliases for later search.

Do not ask the user to choose a narrow research question before this primer is coherent.

## Output
Update `FIELD_MAP.md`.
