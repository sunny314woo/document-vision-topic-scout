# Anchor Paper Selection

## Typical Minimal Set
Normally 8–12 papers:
- 2–3 field-orientation anchors;
- 2–3 target-venue representatives;
- 2–3 +1-tier papers;
- 1–3 recent competitors/frontier papers.

Add a paper only when it answers a recorded question or changes the landscape.
Do not expand into an unbounded review.
