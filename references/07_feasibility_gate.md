# Personal Feasibility Gate

## Default Hard Constraints
- no dedicated equipment;
- public datasets preferred/required;
- CPU or consumer GPU preferred;
- no large cluster;
- avoid large manual annotation;
- avoid expensive paid data/API;
- first-paper scientific complexity beginner-to-moderate.

## Gate Dimensions
Data, compute, equipment, cost, baseline/code availability, evaluation reproducibility, research complexity, engineering complexity, time-to-first-decisive-test, venue fit.

Gate first, rank second.
A hard failure => REJECT.
