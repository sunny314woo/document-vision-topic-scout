# Topic Ranking and Freeze

## Candidate Card
Include:
- Research Question
- Why it matters
- Current state
- Closest prior work
- Already solved
- Appears unresolved
- Gap status
- Novelty confidence
- Search envelope
- Public datasets
- Baselines
- Metrics
- Expected compute/equipment
- Research/engineering complexity
- Target venue fit
- +1 potential
- Fatal risk
- What would kill the topic
- Next reading
- First decisive test
- Verdict

Return at most three candidates.
Use RECOMMEND / HOLD / REJECT.
Only explicit user approval can set `TOPIC_STATUS: FROZEN`.
