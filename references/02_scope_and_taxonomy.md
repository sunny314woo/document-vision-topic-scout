# Scope and Taxonomy

## In Scope
- OCR / text recognition
- handwritten text recognition
- document image enhancement/restoration
- OCR robustness and degradation
- OCR error correction
- confidence / uncertainty / failure detection
- low-resource OCR
- lightweight document vision
- layout/document structure when materially linked to OCR

## Adjacent, Evidence-Only by Default
- scene text
- generic image restoration
- generic CV robustness
- multimodal document understanding
- VLM/document foundation models

Adjacent areas may supply closest prior work but do not automatically enter the feasible candidate pool.

## Out of Default Scope
- autonomous driving
- robotics
- medical imaging
- generic object detection
- large-scale VLM pretraining
- unrelated NLP-only work
